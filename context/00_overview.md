# 00 Overview

`sounduk_backend` — FastAPI backend для музыкального приложения Sounduk.

## Цели

- Предоставить API для регистрации, логина и профиля пользователя.
- Дать пользователю возможность загружать, хранить и стримить треки.
- Поддержать управление альбомами и базовые админ-функции.
- Обрабатывать платежи подписки через YooKassa.

## Бизнес-логика (кратко)

- Пользователь регистрируется, подтверждает email, получает JWT и работает с приватными эндпоинтами.
- Музыкальные файлы и обложки хранятся в S3, метаданные — в SQLite через SQLAlchemy.
- Премиум-статус/лимиты хранилища завязаны на платежи и пользовательские ограничения.
